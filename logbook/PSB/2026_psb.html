Timeline of PSB optics measurements in 2026¶

This page provides quick access links to logbook entries of relevant OMC shifts or measurements and MDs done on the PSB in 2026.

Shift Categorization

The letters in the shifts column have the following meaning:

  • W = Weekdays (Day)
  • WN = Weekdays (Night)
  • H = Holidays or weekend (Day)
  • HN = Holidays or weekend (Night)

1 shift consists of an 8h period, so e.g. 0.5W means a 4h shift on a weekday during daytime.

We consider only the "productive" time for these shifts, i.e. time where the machine is in a stable state suitable for measurements, this is why the number might be lower than the time difference between start and end.

Hovering the column name will show a tooltip with more information.

GUI setup¶

The reference Beta-Beating GUI configuration used for these PSB measurements is /user/psbop/MultiTurn/2026_08_03_Multiturn/multiturn_settings.ini. This is a specific config that has been personalised for PSB measurements — it is not the Beta-Beating GUI's generic default, and should be loaded as the starting point when setting up the GUI for PSB analysis rather than assuming defaults.

As the beta beating GUI is not currently available in the PSB CCM, use jws https://bewww.cern.ch/ap/deployments/applications/cern/lhc/lhc-app-beta-beating-omc3/PRO/BetaBeatingOMC3-Control-3t.jnlp in the terminal to launch the GUI, and then load the above config file.
